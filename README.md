# SkyCast — Professional Weather Dashboard
**Created by: Mahmudul Haq Rupom**

A responsive live weather dashboard made with HTML5, CSS3 and vanilla JavaScript.

## Features
- Search weather by city name
- Current temperature and weather condition
- Today's high and low temperatures
- Humidity, wind speed, UV index and feels-like temperature
- Hourly forecast and 5-day forecast
- Celsius / Fahrenheit switch
- Browser geolocation after visitor permission
- Responsive desktop, tablet and mobile layout
- Free Open-Meteo API; no API key required

## Project structure
- `index.html` — page structure
- `css/style.css` — styling and responsive layout
- `js/app.js` — API integration and app logic
- `assets/` — reserved for optional images

## Run
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Run `index.html` using Live Server.
4. Keep internet access enabled for weather data, fonts and icons.

## API
- Geocoding: https://geocoding-api.open-meteo.com/
- Forecast: https://api.open-meteo.com/
- Provider: https://open-meteo.com/

## Notes
- No API key is needed for this project.
- Browser location generally requires HTTPS or localhost and visitor permission.
- This is a front-end portfolio project; it does not save location history.
